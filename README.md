# FworkNote

轻量级 Windows 图文记事本：粘贴图片、点选图片，把文字和图片按原样复制到任何 Windows 程序。

> 本仓库只提供**下载**，不提供源代码。

## 下载

前往 [Releases](https://github.com/smilelinxi/FworkNote/releases/latest) 下载最新版压缩包：

- 文件名：`FworkNote-<版本>-win64.zip`
- 适用系统：Windows 10 / 11 64 位
- 解压后约 60 MB（已内置所需运行库）

## 安装与使用

1. 下载 zip 后**解压到任意目录**（例如 `D:\Tools\FworkNote`），不要在压缩包内直接双击运行；
2. 双击目录里的 `FworkNote.exe` 即可，无需安装、无需另外下载 Qt 运行库；
3. 首次运行如出现 Windows SmartScreen 提示，选择「更多信息」→「仍要运行」；
4. 建议把 `FworkNote.exe` 固定到任务栏，或为解压目录创建快捷方式。

设置与窗口会话保存在 `%APPDATA%\FworkNote`，程序目录保持纯净，可整体复制到其他电脑继续使用。

## 功能

- **图文混排**：从剪贴板粘贴图片、从资源管理器拖入图片、插入本地图片；单击选中图片，`Ctrl+C` 复制到其他程序
- **目标化复制**：工具栏选择目标后按 `Ctrl+C`，Word/WPS 走 RTF 图文、富文本网页走 HTML、纯文本框只接收文字
- **聊天一键转发**：选择「聊天 · 通用」或「聊天 · 慢速」后 `Ctrl+C`，切到聊天窗口再按 `Ctrl+Alt+V`，按原文顺序交替粘贴文字与图片
- **Markdown 预览与大纲**：`Ctrl+Shift+N` 新建 Markdown，`Ctrl+Alt+1/2/3` 切换编辑 / 分栏 / 预览，侧栏「目录」页可跳转到任意标题
- **多标签页与会话恢复**：关闭窗口不再逐个询问保存，下次启动自动恢复标签、未保存内容与光标位置
- **文件夹面板**：常驻一个文件夹，双击其中的文本文件直接在标签里打开
- **八套主题**：浅色 / 深色 / 暖光 / 暖夜 + 四套莫兰迪，可跟随系统外观切换
- **阅读缩放**：`Ctrl +` / `Ctrl -` / `Ctrl + 鼠标滚轮` 调整，`Ctrl+0` 恢复默认

解压包内附有 `使用说明.txt`。
